# ADR-0028: 単体分析はジャーナルに履歴を残す

- ステータス: 承認済み
- 日付: 2026-08-21
- 関連: [#70](https://github.com/Ries630/StockCopilot/pull/70) / [ADR-0025](0025-journal-as-ledger-and-memo.md)

## 背景

`stock-check` と `stock-screen` は単体でも起動できるが、中間表現JSONと`reports/latest.json`を
作るのは `stock-brief` だけである。単体経路からジャーナル記録も除くと、前回の判断・水準・
候補ゼロの観測を次回へ引き継げない。

## 決定

単体で起動した分析だけはジャーナルに記録する。夕方ブリーフでは定型分析をジャーナルに
書かず、中間表現JSONを正とする。

## 検討した代替

単体経路でも完全な中間表現JSONを組み立てる案は、単体出力にない入力を復元する必要があり、
複製ロジックを増やすため採用しない。

## 結果

単体実行の履歴と夕方ブリーフのJSON履歴は同じ場所に統合されない。両方を同日に実行すると
重複記録を避けるため、夕方ブリーフ側を正とする必要がある。

## 再評価のサイン

単体実行でも完全な中間表現JSONを決定的に生成できる入力が揃ったら、ジャーナル記録を
廃止してJSONへ統合する。
