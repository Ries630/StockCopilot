# ADR-0022: Slack 通知をスクリプトの Incoming Webhook に移す

- ステータス: 承認済み
- 日付: 2026-08-20
- 関連: [#60](https://github.com/Ries630/StockCopilot/issues/60) / [#62](https://github.com/Ries630/StockCopilot/issues/62)

## 背景

夕方ブリーフは 2026-08-12 以降、LLM が Slack MCP (`slack_send_message`) で
`#trading-alerts` に分析結果を投稿している。投稿自体は成功しており、ジャーナルには
毎回 `ts` が残っている。

しかし **Slack は自分の投稿では自分に push を鳴らさない。** 自己メンションも同じで、
本人 identity の投稿に `<@自分>` を書いても通知は発生しない。つまり現状の投稿は
記録としては機能しているが、通知としては機能していない。

兄弟プロジェクトの `trading-copilot-morning-brief` は 2026-08-04 に同じ問題に当たり、
自己 DM を廃止して Incoming Webhook (アプリ identity) に切り替えている。本文先頭の
自己メンションでモバイル push が鳴ることを確認済みで、以降その形で運用している。

りーすさんの要求は「買い判断が含まれる場合のみメンションをつけて通知を飛ばす」。
メンションで push を鳴らすには、**投稿主体がアプリである必要がある**。

加えて、LLM が Slack ツールを呼ぶ形だと、鳴らすかどうかの判断が毎回 LLM の裁量になる。

## 決定

Slack 投稿を `notify.py` が Incoming Webhook で完結させる。**LLM は Slack ツールを
呼ばない。** 投稿は毎日行い、メンションは中間表現
([ADR-0020](0020-intermediate-report-json.md)) の `verdict` が
`lib/verdicts.ACTIONABLE_VERDICTS`（買い / 積増し / 売却）に該当する日だけ付ける。

## 検討した代替

**1. Slack MCP のまま、メンションだけ足す。** 却下。本人 identity のままでは push が
鳴らず、要求そのものが満たせない。

**2. Bot Token で HTML を画像化して添付する。** 却下（今回は）。Slack 内にグラフィックが
直接出るのが利点だが、`files:write` スコープのトークン発行とヘッドレスブラウザの
用意が要る。りーすさんは 4 案（画像添付 / Cloudflare Worker 配信 / ローカル HTML +
リンク / Slack Canvas）から「ローカル HTML + リンクのみ」を選んだ。

**3. 資金が動く判断のある日だけ投稿する（morning brief と同形）。** 却下。静穏日に
何も出ないと「実行されて静穏だった」のか「実行されなかった」のかが Slack だけでは
区別できない。夕方ブリーフは毎営業日走るので、日次の投稿に実行の生存確認を兼ねさせる。
morning brief が月 4〜5 回しか鳴らないのは、そちらのシグナルが月 4〜5 件だからである。

**4. 「部分利確」もメンション対象に含める。** 却下。りーすさんが 買い / 積増し / 売却 の
3 つと決めた。

## 結果

**投稿先を実行時に選べなくなった。** Webhook はチャンネルがアプリ側で固定される。

**投稿の `ts` が取れなくなった。** Webhook のレスポンスは `ok` だけで、
ジャーナルに `ts` を残す従来の運用は続けられない。スレッドへの追補もできないため、
訂正は次のエントリと次の投稿で行うことになる。

**ファイルを添付できない。** HTML そのものを Slack に載せる道はこの方式では閉じた。
載せたくなったら代替 2 を別の ADR で検討する。

**実行環境に `.env` の前提が増えた。** `SLACK_WEBHOOK_URL` が未設定なら投稿しない。
黙って落とさず、スキップ理由を標準出力に出す。

## 再評価のサイン

- 静穏日の投稿がノイズだと感じるようになったら、発火条件を morning brief と揃える
- Slack の中で HTML／グラフィックを見たくなったら、代替 2 を別の ADR で検討する
- メンション対象のラベルを変えるときは `lib/verdicts.py` と
  `tests/test_report.py` の固定テストを同時に直す
