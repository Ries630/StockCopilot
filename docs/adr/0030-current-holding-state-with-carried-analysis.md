# ADR-0030: 現在の保有状態へ市場別の分析結果を合流する

- ステータス: 承認済み
- 日付: 2026-08-22
- 関連: Issue #75 / ADR-0029

## 背景

ADR-0029で、確定足が`unchanged`または`unavailable`の市場は前回分析を引き継ぐと決めた。
最初の実装は前回のPositionオブジェクト全体を採用したため、市場休場中に執行記録で株数が
変わると、最新の実効保有とレポートの`holdings`が食い違った。同じ原因で、新規保有が消え、
全売却した銘柄が残り、`reference_only`の変更も反映されない。

市場観測の鮮度と、現在何を保有しているかの鮮度は別である。どのフィールドを今回値と
前回値のどちらが所有するかを決める必要がある。

## 決定

最終`holdings`の銘柄集合とidentity/state（`ticker` / `name` / `shares` / `currency` /
`reference_only`）は、常に今回計算した実効保有を正とする。

`updated` / `initial`市場では今回分析を使う。`unchanged` / `unavailable`市場では、現在も
保有している同一銘柄に限って前回の判断・価格・水準・シグナル・散文を引き継ぐ。前回分析が
無い新規保有は存在を隠さず、`analysis_status: unavailable`の状態だけを表示する。
全売却して今回の実効保有から消えた銘柄は、前回分析があっても引き継がない。

分析の由来は`analysis_status`の`current` / `carried` / `unavailable`で表す。候補は保有台帳では
ないため、ADR-0029どおり市場単位で今回または前回の結果集合を選ぶ。

## 検討した代替

- **停滞市場のPosition全体を前回から採用する。** 株数、新規保有、全売却、判断対象区分が
  現在の実効保有と食い違うため不採用。
- **`shares`だけ今回値で上書きする。** 新規保有、全売却、`reference_only`の変更を直せず、
  同じ所有権問題をフィールド追加のたびに繰り返すため不採用。
- **停滞市場も再分析する。** 同じ確定足から新しい判断と散文を生成しないというIssue #75の
  目的に反するため不採用。

## 結果

- Positionは現在の保有状態だけを持ち、分析を持たない場合がある。描画側はその銘柄を消さず、
  判断・水準・トリガーが無いことを明示しなければならない。
- 前回分析を引き継げるのは、今回も存在する同一ticker・currencyの保有だけになる。
- 分析と保有状態をPosition内のフラットなキーで持つ構造は維持するため、合流処理が
  identity/stateフィールドと分析フィールドの所有権を管理する必要がある。

## 再評価のサイン

- Positionのidentity/stateまたは分析フィールドが増え、所有権リストの保守漏れが起きたとき。
- 同一ticker・currencyを複数の独立した保有としてレポートする必要が生じたとき。
- 中間表現で保有状態と分析をネストした別オブジェクトへ分離するとき。
