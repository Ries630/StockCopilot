# ADR-0002: 分析ジャーナル本体をリポジトリで追跡する

- ステータス: 廃止（[ADR-0008](0008-no-holdings-in-repo.md) により置換）
- 日付: 2026-08-06
- 関連: `4fa1e92`、設計メモ `~/.claude/plans/tradingcopilot-trading-copilot-morning-b-toasty-duckling.md`

## 背景

保有分析は 1 回で完結しない。次回の分析は前回エントリとの突合から始まるので、
継続記録そのものが分析の入力になる。

TradingCopilot は `swing/journal.md` をプロジェクト内に置き、1 回の分析 = 1 エントリ、
銘柄ごとにシナリオ・主要水準・判断 (ホールド/積増し/利確) を残し、運用ルールとして
固まった教訓は SKILL.md へ昇格させる運用を既に確立していた。

このプロジェクトの当時の配置は `~/Documents/Claude/Projects/StockCopilot` で、
TradingCopilot / Investment と並ぶ作業ディレクトリだった。公開は前提になっていない。

## 決定

`journal/journal.md` をリポジトリ内に置き、git で追跡する。書式の説明はファイル冒頭に書く。

## 検討した代替

（記録に無い）設計メモは TradingCopilot の journal 運用パターンを流用元として挙げているだけで、
他の置き場所を比較した記録は残っていない。

## 結果

- 分析の継続記録が git 履歴に入る。過去のエントリを追え、他マシンにも持ち運べる
- 書式の説明と記録本体が同じファイルに同居する。書式だけを参照したい場面で
  記録全体を読むことになる
- **保有銘柄・株数・売買判断の時系列が git 履歴に残る。**
  公開した時点で取り消せない

## 廃止の経緯

同日 2026-08-06 に `~/Repositories/StockCopilot` へ移して public 公開したため、
`71476a6` で追跡を止めた。

追跡されていたのは見出しと書式の説明 8 行だけで、エントリは 1 件も書かれていなかった。
履歴への保有情報の混入は起きていない。

書式仕様は `journal/README.md` に分離して追跡を続け、本体は `.gitignore` に落とした。
置換先は [ADR-0008](0008-no-holdings-in-repo.md)。
